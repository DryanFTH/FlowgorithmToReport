# FlowgorithmToReport
Lama dalam membuat laporan tugas flowgorithm? tidak mengerti notasi deskripsi yang terstruktur? atau ingin menghemat waktu agar bisa melakukan hal lain?

FlowgorithmToReport adalah solusi baru! hanya dengan mengisi kolom kolom akan dibuatkan otomatis laporan yang kamu butuhkan secara instan!

### Cara Penggunaan

1. Buat flowchart menggunakan flowgorithm
<img src="/public/steps/image1.webp" width="300px">
2. Buka source code viewer
<img src="/public/steps/image2.webp">
3. Pilih bahasa nya menjadi Auto Pseudocode
<img src="/public/steps/image3.webp">
4. Salin source code nya
<img src="/public/steps/image4.webp">
5. isi kolom pada website yang sudah di deploy di [github page repository ini](https://dryanfth.github.io/FlowgorithmToReport/)
<img src="/public/steps/image5.webp">
6. Tempel hasil salinan source code tadi di kolom besar di tengah
<img src="/public/steps/image6.webp">
7. Upload Gambar yang kamu inginkan, lalu klik Buatkan
<img src="/public/steps/image7.webp">
8. Akan ada file yang terdownload, buka dan jadilah laporan tugas yang kamu mau
<img src="/public/steps/image8.webp">
